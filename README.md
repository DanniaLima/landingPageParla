# Parla! 🇮🇹 — Landing Page

Este repositório contém o código-fonte da landing page de vendas do **Parla!**, um aplicativo web de ensino de italiano focado em conversação prática para brasileiros.

> **Nota:** Este é um projeto isolado (standalone). O código principal do aplicativo (React SPA) encontra-se em um repositório separado para garantir deploys independentes e maior segurança.

---

## 🚀 Tecnologias Utilizadas

O projeto foi construído com foco em performance, SEO e facilidade de manutenção:

- **[React](https://reactjs.org/)** + **[TypeScript](https://www.typescriptlang.org/)**
- **[Vite](https://vitejs.dev/)** (Build tool)
- **[Tailwind CSS](https://tailwindcss.com/)** (Estilização)
- **[Lucide React](https://lucide.dev/)** (Ícones)
- **[Framer Motion](https://www.framer.com/motion/)** (Micro-interações e animações)

---

## ⚙️ Como rodar o projeto localmente

**Pré-requisitos:** Node.js (versão 18+) e npm instalados.

```bash
# 1. Clone este repositório
git clone https://github.com/DanniaLima/landingPageParla.git

# 2. Acesse a pasta do projeto
cd landingPageParla

# 3. Instale as dependências
npm install

# 4. Inicie o servidor de desenvolvimento
npm run dev
```
